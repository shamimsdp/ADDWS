# Project capability guide

This is a project reference document, not an installed Codex skill or executable tool definition.

## Capabilities needed

- Apparel domain modeling: style/color/size matrix, size ordering, season/collection and exchanges.
- Inventory engineering: transactional ledgers, reservations, costing, receipt aging and reconciliation.
- Retail delivery: barcode/printer hardware, cash shifts, offline queues and operator-friendly checkout.
- Integration engineering: provider contracts, webhook authentication, retries, mapping and COD settlement.
- SaaS security: tenant isolation, role/location access, device/session policies and recovery.
- Analytics: defined merchandising metrics, availability history and forecast backtesting.
- Bangladesh localization: Bangla/English UX, BDT, local phone/address formats and reviewed tax requirements.

## Applying available skills

Use an installed skill only when its actual scope matches the task. Read its SKILL.md and announce first use. Auth/database-specific skills become relevant after those technologies are selected. Do not treat this file as approval to install dependencies, publish services or contact customers.

Skills do not determine the delivery lane or justify extra agents. Apply the smallest relevant skill set, read only its required references and keep execution within the Fast / Standard / Deep lane recorded for the task.

## Reference order

User decisions → project context/rules → approved architecture and business policies → relevant installed skill → official version-specific library/provider documentation.
